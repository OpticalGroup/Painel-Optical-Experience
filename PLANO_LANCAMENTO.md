## 💡 Insights de Quem Já Vendeu Sistema para Empresas

### Verdade 1: Decisor Não É Usuário
- **Decisor**: CFO, Diretor Financeiro (quer ROI)
- **Usuário**: Coordenador, Operador (quer facilidade)

**Estratégia dual**: 
- Pitch financeiro para decisor
- Demo hands-on para usuário

### Verdade 2: Empresa Compra Medo, Não Oportunidade
- ❌ "Ganhe eficiência" (meh)
- ✅ "Evite perder R$ 180k" (atenção!)

**Sempre comece com dor/medo, termine com sonho.**

### Verdade 3: Preço É Percepção
- R$ 500/mês parece caro
- R$ 500/mês vs R$ 536k/ano salvos = **barganha insana**

**Sempre ancoragem: mostre o custo do problema ANTES do preço.**

### Verdade 4: Trial Vence Features
- Lista de 50 features = confusão
- Trial de 14 dias = experiência

**Deixe cliente testar. Sistema bom se vende sozinho.**
